ESP32 Companion Robot V1

In development · inspired prototype

Published OLED facial-display code. Currently a static-face module; hardware validation is unconfirmed.

ESP32 / Arduino C++ / I²C / SSD1306

The code initializes I²C and a 128×64 SSD1306, draws eyes and a mouth, and submits the display buffer. loop() is empty. V1 is inspired by the original Xiaohongshu creator’s public robot-building approach, with some hardware materials and configuration adapted to personal needs.

Current scope & limitations

No hardware was connected or tested in this work. Animation, networking, voice, conversation, motion and autonomy are not implemented. V1 is not a wholly independent original design; the creator’s name and code provenance are not independently verified. The original attribution link is retained.

V1 inspiration: original Xiaohongshu creator

Future plans

V2: independent design; V3: future independent development. Both are plans only, with no completed versions or verified features.
