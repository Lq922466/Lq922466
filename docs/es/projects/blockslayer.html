BlockSlayer

En desarrollo · prototipo inicial

Un prototipo de bloques y combate contra slimes: coloca piezas, elimina líneas y conserva espacio para combatir.

Flutter / Dart / Provider / SharedPreferences

La documentación describe un tablero 8×8, modo clásico y contrarreloj. La implementación posterior incluye vida enemiga, ataques por líneas y turnos contados por colocaciones correctas. Las descripciones proceden de revisar el código, sin validación de ejecución en este trabajo.

Alcance actual y límites

No hay instalador público. La interfaz conserva BLOCK CRUSH y está en inglés. El README original agradecía el proyecto block-crush-game de Md Rounaq Ali; faltan por verificar URL, licencia, permisos y alcance de cambios. No se atribuye todo el trabajo original a INNNX. El código sigue privado.
