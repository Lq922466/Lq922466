Robots e IoT

Robot de compañía ESP32 V1

En desarrollo · prototipo inspirado

Código de expresión facial OLED publicado. Actualmente es un módulo de cara estática; la validación física no está confirmada.

ESP32 / Arduino C++ / I²C / SSD1306

El código inicializa I²C y una SSD1306 de 128×64, dibuja ojos y boca y envía el búfer. loop() está vacío. V1 se inspira en el enfoque público del creador original de Xiaohongshu, adaptando algunos materiales y configuraciones a necesidades personales.

Alcance actual y límites

No se conectó ni probó hardware en este trabajo. No hay animación, red, voz, conversación, movimiento ni autonomía implementados. V1 no es un diseño totalmente independiente; el nombre del creador y el origen del código no se verificaron de forma independiente. Se conserva el enlace de atribución.

Inspiración V1: creador original de Xiaohongshu

Planes futuros

V2: diseño independiente; V3: desarrollo independiente futuro. Ambos son planes, sin versiones completadas ni funciones verificadas.
