Infraestructura y seguridad

Refuerzo de servidor Linux

Completado · alcance del laboratorio documentado

Un laboratorio de Ubuntu virtual con autenticación SSH por claves, reglas UFW e integración manual de Fail2ban.

Ubuntu Server / VirtualBox / OpenSSH / UFW / Fail2ban

Se creó un administrador sudo, se configuró Ed25519, se desactivaron el acceso root y las contraseñas y se comprobó la configuración SSH efectiva. UFW rechaza entradas por defecto y permite salidas y SSH. El bloqueo y desbloqueo manual verificaron la integración Fail2ban–UFW.

Alcance actual y límites

No se probó directamente la detección automática de accesos fallidos. Se identificaron actualizaciones pendientes sin demostrar su instalación completa. “Completado” se refiere al alcance registrado.
