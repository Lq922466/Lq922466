PASS / Party Games

En desarrollo · demo preliminar Android

Un teléfono. Todos juegan. Una colección de preguntas, retos, selección aleatoria de jugadores y respuestas cronometradas.

Flutter / Dart / Android

Las nueve entradas incluyen Verdad o reto, Bomba numérica, Quién es más probable, Yo nunca, Reto de 5 segundos, Fiesta de cumpleaños, Verdad, Reto y Modo mixto. La app ofrece chino, inglés y español; las preguntas principales funcionan sin conexión.

Alcance actual y límites

GitHub Releases ofrece la demo Android v1.0.0 para Android 7.0+. Es una demo preliminar, aún sin publicación oficial en Google Play, con anuncios de prueba de Google. El código, las preguntas y las firmas permanecen privados. El funcionamiento en iOS no está confirmado.
