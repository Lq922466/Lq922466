机器人与物联网

PaperRobot V2 · ESP32 纸板机器人

V2 实物演示已公开 · 逐项测试待记录

从 V1 静态 OLED 页面更新到已公开的 V2 集成固件与实物演示：表情、红外互动、转头与触摸点头。

ESP32-C3 SuperMini / SSD1306 / 2× SG90 / 2× IR / TTP223 / Arduino C++

源码包含六种面孔数据、眨眼和平滑过渡。左右红外使整张脸横移并控制转头；两侧同时触发时回中。触摸触发开心表情与一次点头，45 秒无活动后进入睡眠表情。2026-10-13 的仓库报告记录 11 个程序编译通过。用户表示实物已完成并提供约 74 秒演示；视频未与确切烧录固件哈希绑定。

当前范围与限制

编译与演示不等于完整硬件验收：逐项实测、持续运行、最终供电接法、零件精确额定值、制作照片与尺寸仍待补充。没有摄像头、语音、联网或 AI 对话功能。V1 历史代码和文档保留；当前 V2 仍是参考改编，不宣称独立原创。

实际硬件与接线

ESP32-C3 SuperMini ×1；SSD1306 128×64 I²C OLED ×1（0x3C，SDA 0 / SCL 1）；SG90 ×2（转头 GPIO4，俯仰 GPIO5）；红外模块 ×2（GPIO6/7）；TTP223 ×1（GPIO10）。5V UBEC 给舵机供电并共地；12V 只接 UBEC 输入。现有大面包板与手工测量裁切的 3mm 瓦楞纸板外壳，无裁切模板。

组装与调试路径

文档建议：先独立测试 USB、OLED、IR、触摸与舵机；按实际零件裁切纸板；拆舵盘回中 90°，断电后安装；预留检修口和线缆余量。确认供电与共地后空载上传 V2，再逐步加载。Arduino 选择 ESP32C3 Dev Module，串口 115200。此为仓库重建指南，制作照片与真实步骤记录尚待补充。

技术挑战

OLED ACK 仅代表总线响应，不能证明可见像素：先扫描地址，再做独立显示测试。输入使用 40ms 去抖，触摸需释放后重触并等待 2200ms 冷却。舵机每 20ms 最多走 1°，默认转头 80–100°、俯仰 82–98°；软件限位不保证机械安全。抖动或重启需排查供电压降、共地、接触与机械堵转。
