# Robots & IoT

Small hardware experiments and companion-device prototypes, showing the functionality implemented so far.

| Project | Status | Technologies | Link |
| --- | --- | --- | --- |
| ESP32 Companion Robot V1 | **In development** | ESP32, Arduino/C++, I²C, Adafruit GFX / SSD1306 | [Repository](https://github.com/Lq922466/esp32-companion-v1) |

The reviewed firmware initializes a 128×64 SSD1306 OLED over I²C and draws a static face. The current loop is empty. Movement, speech, AI conversation and autonomous behavior are not implemented in the published code.

Only the completed, reviewed OLED firmware is public.
